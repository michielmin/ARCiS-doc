# Output Files

There are many output files, most are for checking the model. The most important ones are discussed here.

 | File Name           | Description                                      |
 |---------------------|--------------------------------------------------|
 | log.dat             | The log file containing the runtime output.      |
 | input.dat           | Copy of the input file used.                     |
 | mixingratios.dat    | Temperature structure and molecule abundances.   |
 | trans               | Transmission spectrum.                            |
 | emis                | Emission spectrum.                               |
 | emisR               | Emission spectrum relative to the stellar emission.|
 | .txt                | File containing the MultiNest output.            |
 | bestfit.dat         | File containing the input file for the best fit. |
