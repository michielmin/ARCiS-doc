# 3D models and phase curves

ARCiS can build a pseudo-3D planet from a set of 1D atmospheres, following
[Chubb & Min (2022)](../citing.md). This is used to compute phase curves, emission at
different phases, and limb-dependent transmission spectra, and to retrieve 3D
structures from phase-curve data.

## The β-map

The planet is divided into `nlong` × `nlatt` cells (default 36 × 19). Each cell gets a
value β that sets how much irradiation that location effectively receives. The static
β-map is

\[
\beta_\star=\cos\Lambda\cos\Phi\ \ \text{(dayside)},\qquad \beta_\star=0\ \ \text{(nightside)},
\]

with Λ and Φ longitude and latitude. Heat redistribution is then modelled by solving a
diffusion (and advection) equation with β<sub>⋆</sub> as source term, giving the final
β-map. Instead of computing a 1D model for every cell, `n3D` 1D models are computed for
a range of β values and interpolated.

For example:

```ini
run3D=.true.
n3D=10
night2day=0.5
par_tprofile=.true.
```

| Keyword | Default | Meaning |
|---|---|---|
| `run3D` | `.false.` | Compute a 3D model |
| `n3D` | 10 | Number of 1D models (β values) |
| `nlong`, `nlatt` | 36, 19 | Number of longitude and latitude cells |
| `night2day` | 0.5 | Night-to-day redistribution efficiency |
| `pole2eq` | 1 | Pole-to-equator redistribution |
| `hotspotshift` | | Longitudinal shift of the hot spot [degrees] |
| `tidallock` | `.true.` | Tidally locked planet |
| `Kxx`, `Kyy`, `vxx` | | Diffusion and advection parameters of the β-map |
| `phase<n>` | 180 | Phases at which spectra are computed (180 = dayside) |
| `output3D` | `.false.` | Write the full 3D structure |

Retrieval parameters can vary across the planet with `par3d` keywords, interpolating
between a nightside and a dayside value.

For emission spectra including scattering it is adviced to always use ARCiS in 3D mode.
If you do not want a 3D model, it is best to use:

```ini
run3D=.true.
n3D=3
night2day=1
hotspotshift=0
```

These settings effectively create a fully homogeneous (1D) planet with minimal overhead.
However, it does trigger the more accurate and fast scattering mode.

## Energy balance with varying albedo

When the albedo differs between the day- and nightside (for example due to clouds that
only form on the nightside), the β-map is rescaled iteratively to conserve energy
(`nalbedo_iter`). The method is described in [Albedo iteration](../theory/albedo-iteration.md).

## Reading a full 3D structure

A 3D structure from, e.g., a general circulation model can be read with
`full3Ddir='<directory>'` (this sets `readFull3D=.true.`). The number of 1D models must
then equal `nlong × nlatt`; the β-map settings are ignored.
